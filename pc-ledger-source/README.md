# PC Ledger

สมุดซื้อขายและสเปกคอมส่วนตัว ธีมฟ้า–ขาว ใช้ HTML, CSS และ JavaScript เปิดใช้งานได้โดยไม่ต้องติดตั้ง npm หรือใช้บัญชี ChatGPT

## ย้ายข้อมูลจากไซต์เดิม

1. เปิด [ไซต์เดิม](https://pc-ledger-p.handycroft.chatgpt.site) ในเบราว์เซอร์ที่เคยบันทึกรายการ แล้วกด **สำรองข้อมูล**
2. เก็บไฟล์ JSON ไว้ในเครื่อง เพราะมีรายการซื้อขาย ราคา และสเปกของคุณ
3. เปิดเว็บใหม่ แล้วกด **กู้ข้อมูล** เลือกไฟล์ JSON และตรวจยอดกับไซต์เดิม การกู้ข้อมูลจะแทนที่ข้อมูลในเบราว์เซอร์ของเว็บที่เปิดอยู่
4. สำรองข้อมูลอีกครั้งเมื่อมีการเปลี่ยนแปลงที่ต้องการเก็บ

## ใช้ส่วนตัวในเครื่อง

เก็บซอร์สใน GitHub แบบ Private แล้วดาวน์โหลดหรือ clone มาใช้ในเครื่อง เปิด Terminal ในโฟลเดอร์ที่มี index.html แล้วรัน

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

บน Windows ใช้ `py -m http.server 8000 --bind 127.0.0.1` หากเรียก Python ผ่าน `py` จากนั้นเปิด http://127.0.0.1:8000 ในเบราว์เซอร์

เปิดด้วย URL และเบราว์เซอร์เดิมทุกครั้ง เพื่อให้เว็บเข้าถึงข้อมูลที่บันทึกไว้ การเปลี่ยนเบราว์เซอร์ เครื่อง โดเมน หรือพอร์ตต้องย้ายข้อมูลด้วยไฟล์สำรอง ฟอนต์และรูปที่อ้างอิงจากเว็บภายนอกต้องใช้อินเทอร์เน็ต

## เปิดออนไลน์ผ่าน GitHub Pages

1. อัปโหลดไฟล์ในโฟลเดอร์นี้ให้ `index.html` อยู่ที่ root ของ repository บน branch `main`
2. ไปที่ **Settings → Pages → Deploy from a branch** เลือก `main` และ `/(root)` แล้วกด **Save**
3. เปิด URL ที่ GitHub Pages แสดง แล้วกด **กู้ข้อมูล** ในหน้าเว็บ

บน GitHub Free ต้องใช้ public repository สำหรับ GitHub Pages หน้าเว็บและซอร์สที่เผยแพร่เปิดดูได้ทั่วไป ตัวซอร์สชุดนี้เริ่มจากบัญชีว่าง ข้อมูลที่กู้หรือกรอกจะอยู่ในพื้นที่เก็บข้อมูลของเบราว์เซอร์ การกู้ข้อมูลไม่อัปโหลดไฟล์ไป GitHub ให้เก็บไฟล์สำรองไว้นอก repository
