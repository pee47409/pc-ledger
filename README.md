# PC Ledger

สมุดคอมส่วนตัว ธีมฟ้า–ขาว รองรับมือถือ ใช้ Supabase Auth และฐานข้อมูลกลาง พร้อมนำเข้าไฟล์สำรองเวอร์ชันเดิม

## ตั้งค่าครั้งแรก

1. ใน Supabase ไปที่ Authentication > Users > Add user > Create new user สร้างบัญชี pee47409@gmail.com และตั้งรหัสผ่านเอง หากมี Auto Confirm ให้เปิดเพื่อใช้บัญชีที่สร้างเองได้ทันที
2. ไปที่ Authentication > Sign In / Providers ปิด Allow new users to sign up และ Allow anonymous sign-ins
3. เปิด SQL Editor วางเนื้อหา supabase-setup.sql ทั้งไฟล์แล้วกด Run SQL จะผูกสิทธิ์เจ้าของกับ user ID ของอีเมลข้างต้น หากต้องการใช้อีเมลอื่น แก้อีเมลใน SQL ก่อนรัน
4. เปิด https://pee47409.github.io/pc-ledger/ ล็อกอินด้วยบัญชีที่สร้างไว้
5. กด ย้ายข้อมูลเดิม เพื่อย้ายรายการที่เก็บในเบราว์เซอร์นี้ขึ้นคลาวด์ หรือกด กู้ข้อมูล แล้วเลือก JSON ที่สำรองจากไซต์เดิม
6. เปิดเว็บจากอีกเครื่อง ล็อกอินบัญชีเดียวกันแล้วตรวจยอด

เว็บไซต์ใช้ Publishable key สำหรับเชื่อม API สิทธิ์เข้าถึงข้อมูลตรวจโดย RLS ที่ฐานข้อมูล มีเพียง user ID ที่ระบุในตาราง pc_ledger_owners ที่ได้รับสิทธิ์ ตารางนี้แก้ไขได้ผ่าน Dashboard ด้วยสิทธิ์ผู้ดูแลเท่านั้น

ข้อมูลโหลดใหม่ทุก 30 วินาทีเมื่อเปิดเว็บและปิดแบบฟอร์ม รวมถึงเมื่อกลับมายังแท็บ กดโหลดล่าสุดได้เอง ระบบตรวจ revision ก่อนบันทึกเพื่อป้องกันการเขียนทับข้อมูลจากอีกเครื่อง หากมีข้อมูลใหม่ ให้เก็บข้อความที่กำลังแก้ไข แล้วโหลดล่าสุดก่อนทำรายการใหม่

ข้อมูลบัญชีซื้อขายเก็บบนคลาวด์ สถานะล็อกอินเก็บในเบราว์เซอร์ ปุ่มออกจากระบบล้างการแสดงข้อมูลและเซสชันในเครื่องนี้ ข้อมูลเก่าใน localStorage คงอยู่เพื่อให้ย้ายเข้าระบบได้ ใช้ปุ่มสำรองข้อมูลเพื่อเก็บสำเนา JSON ไว้ในเครื่อง

## โฮสต์เอง

อัปโหลด index.html, style.css, app.js, cloud.js และ supabase.js ที่ root ของ GitHub Pages หรือโฮสต์ static อื่น ไม่ต้อง build

supabase.js เป็น Supabase JavaScript SDK เวอร์ชัน 2.89.0 จากแพ็กเกจ @supabase/supabase-js บน jsDelivr ใบอนุญาต MIT ฟอนต์และรูปจากลิงก์ภายนอกต้องใช้อินเทอร์เน็ต
